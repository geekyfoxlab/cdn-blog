# 主站与博客导航

## 站点关系

```text
https://example.com
└── 独立个人主页

https://blog.example.com
└── 本仓库构建的独立博客
```

两个站点不共享源码、路由或构建流程。博客只通过 `src/config/site.ts` 中的 `mainSiteUrl` 为导航中的“主站”提供跨站地址。

## 博客入口行为

- 博客 Logo 和站点名称链接到博客内部 `/`。
- 桌面导航和移动菜单中的“主站”指向 `https://example.com`。
- 页脚和 About 中的“返回 Example Lab 主页”指向博客内部 `/`。
- 404 页面提供博客首页和归档入口，不跳转主站。
- 主站导航使用标准 `<a>` 元素和 HTTPS，在当前标签中打开，不依赖 JavaScript。
- 外部地址标识与新标签行为是两个独立配置，不会因为链接跨域而强制打开新标签。

## 未来兼容

未来主站可以增加博客、项目、工具等入口，但不需要修改博客构建。若主站域名发生变化，只需更新 `mainSiteUrl` 并确认导航行为；不要把主站页面复制进博客仓库。
