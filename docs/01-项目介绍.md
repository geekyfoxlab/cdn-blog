# 项目介绍

## 定位

本仓库是 Example Lab 的独立博客项目，面向 Python、AI 应用开发、大模型与 Agent、数据采集、项目开发记录和公开知识笔记。

博客正式地址：

```text
https://blog.example.com
```

主站地址：

```text
https://example.com
```

主站不属于本仓库。博客只通过 `src/config/site.ts` 中的 `mainSiteUrl` 提供普通 HTTPS 链接，不读取主站文件、不嵌入 iframe，也不依赖主站在线才能构建。

## 当前发布状态

仓库中的上游示例文章均已标记为草稿，生产构建因此不会生成文章详情页、文章列表项、RSS 条目或 Pagefind 文章索引。当前首页和归档页会显示“暂无公开文章”状态，这是有意设置的内容边界，不是构建失败。

发布第一篇文章前，需在 `src/content/posts/` 新建或编辑 Markdown 文件，并完成 [文章写作规范](04-文章写作规范.md) 中的 Frontmatter 和内容检查。

这些功能应在单独阶段评估，不能为了提前占位而引入后端服务或生产凭据。

## 运行与验证

本地安装和检查方式见 [本地开发](03-本地开发.md)。基础验证命令为：

```sh
pnpm check
pnpm type-check
pnpm exec biome check ./src
pnpm build
```

`pnpm build` 的输出目录是 `dist/`，并在构建后生成 Pagefind 索引。生产发布前还应检查 `dist/404.html`、RSS、Sitemap、robots 和页面 Canonical，具体清单见 [SEO 说明](10-SEO说明.md)。
